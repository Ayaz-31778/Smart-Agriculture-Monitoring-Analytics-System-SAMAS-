## Installation Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ayaz-31778/Smart-Agriculture-Monitoring-Analytics-System-SAMAS-
   cd Smart-Agriculture-Monitoring-Analytics-System-SAMAS-
   ```
2. **Install required dependencies:**
   Ensure you have Python installed, then run the following:
   ```bash
   pip install -r requirements.txt
   ```

## Usage Guidelines
1. **Start the system:**
   Run the main application using:
   ```bash
   python main.py
   ```
2. **Access the dashboard:**
   Navigate to `http://localhost:5000` in your web browser to access the monitoring dashboard.

## Features
- Real-time sensor data collection
